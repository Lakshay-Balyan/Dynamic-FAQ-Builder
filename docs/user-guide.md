# User Guide

This guide explains how to use the Dynamic FAQ Builder admin dashboard to manage your knowledge base. This guide is intended for **Content Managers (Admin/Editor roles)**.

## 1. Accessing the Dashboard

You must have an account to access the dashboard.
1.  Navigate to the main URL (e.g., `http://localhost:5173/`).
2.  Enter your **Username** and **Password** and click "Log In".
3.  If you do not have an account, click the **"Create an account"** link, fill out the form, and then log in.

## 2. Admin Dashboard Overview

After logging in, you will see the Admin Dashboard. This is your main control panel, split into two sections: "Manage Categories" and "Manage FAQs".

[Image of Admin Dashboard layout]

### Managing Categories

You must create a category *before* you can create an FAQ.

1.  In the **"Manage Categories"** widget on the left, you will see a list of all existing categories.
2.  To create a new one, type the category name (e.g., "Billing", "Technical") into the "New category name..." input box.
3.  Click **"Add"**. The new category will appear in the list and in the "Create New FAQ" form.

### Managing FAQs

#### Creating an FAQ
1.  In the **"Create New FAQ"** form, select a category from the dropdown.
2.  Type the full question into the "Question" box.
3.  Type the full answer into the "Answer" box.
4.  Click **"Create FAQ"**.
5.  Your new FAQ will immediately appear in the **"Existing FAQs"** table at the bottom of the page.

#### Editing an FAQ
1.  Find the FAQ you wish to change in the "Existing FAQs" table.
2.  Click the blue **"Edit"** button.
3.  A pop-up modal will appear with the FAQ's information.
4.  You can change the question, the answer, or the category.
5.  Click **"Save Changes"** to update the FAQ.

#### Deleting an FAQ
1.  Find the FAQ you wish to remove in the "Existing FAQs" table.
2.  Click the red **"Delete"** button.
3.  A confirmation box will appear. Click **"OK"**.
4.  The FAQ will be permanently deleted and will disappear from the list.

## 3. Viewing Analytics

From the main dashboard, you can track your FAQ performance.

1.  In the header, click the **"View Analytics"** link.
2.  You will be taken to the Analytics Dashboard, which displays three reports:
    * **Top 10 Viewed FAQs:** Shows which questions are being viewed the most.
    * **Top 10 Search Terms:** Shows what users are searching for most often.
    * **Top 10 Zero-Result Searches:** Shows what users are searching for but *not* finding. This is the most important report for identifying gaps in your knowledge base.
